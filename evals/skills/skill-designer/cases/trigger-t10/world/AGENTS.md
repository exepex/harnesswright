# Agents

Rules for agents working in this toolkit. It holds the skills our teams install, as templates under
`v2/skills/`, and the roles and rules they use.

## Portable templates

- A template names no tool that only one host has, and no model.
- Its frontmatter keeps no field that only one host reads, such as `allowed-tools`.
