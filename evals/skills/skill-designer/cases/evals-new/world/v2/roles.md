# Roles

| Role | Does | Produces |
|---|---|---|
| implementer | Writes the code and tests for one story | A change on a branch |
| release manager | Tags a version and publishes its notes | Release notes |

## Jobs

| Job | Roles | Skills in order | `rest` skill |
|---|---|---|---|
| release | release manager | release-notes | release-notes |
| review prep | implementer | pr-summary | pr-summary |
