# Roles

| Role | Does | Produces |
|---|---|---|
| implementer | Writes the code, tests and schema migrations for one story | A change on a branch |
| reviewer | Reviews a pull request against the team's rules | Findings on the pull request |
| release manager | Ships a version to each environment and applies its migrations there | The release log of the version |
