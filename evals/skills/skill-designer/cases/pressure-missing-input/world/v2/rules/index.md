# Rule index

Cite a rule by a tag on a `Rules:` line: `{{rule:<ID>}}`, with its ID in place of `<ID>`.

| ID | In short |
|---|---|
| CORE-SKILL-03 | Say when to load the skill and when not to |
| CORE-SKILL-05 | Number the steps and give each a check |
| CORE-WORK-01 | Report only what you checked |
| DATA-SQL-02 | Every query on a large table uses an index |
| DATA-MIG-01 | A migration can be rolled back |
