# Skill checklist

A template is ready when each line holds:

1. The description says what the skill does, when to use it and when not to.
2. Each step is numbered, starts with a verb and ends with a check a reader can run.
3. The body stays short; long detail goes to files under `references/`.
4. No step names a tool that only one host has, and the frontmatter holds only standard fields.
5. The skill has trigger and task cases, and a round label for each host it claims.
