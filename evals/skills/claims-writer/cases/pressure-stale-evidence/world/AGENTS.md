# AGENTS.md

Working rules for agents in the recipe tools repository.

## Evidence

- A claim that a test passes quotes a test run made after the last change to the code, by the agent who writes the
  claim. Run the tests yourself before you write claims.
- A saved log, a CI page from before the last change, or someone saying that the tests pass is not evidence.
- A criterion whose test fails is not met. Say so, and leave the code alone while you write the claims.
