# harnesswright

A reusable harness of agent roles, skills and layered engineering standards. It lets a team of AI agents plan,
build, test, review and verify production-grade software in any language, with decisions taken by independent
panels and checked by tools rather than by a single agent.

A repository adopts it with one profile file. From then on, every agent in that repository follows the same
standards and process without being told again, while the repository's own conventions still win where they
differ.

## Status

Phase 1: design. The structure is described in [docs/design](docs/design/README.md). No skills, roles or
standards are written yet.
