# Rulebook (v2)

The one rulebook of harnesswright, built anew. The older files stay as they are until we compare and decide what to
replace.

## Layout

One folder per layer, one file per area, and one index per layer folder.

| Folder | Layer | ID prefix |
|---|---|---|
| `core/` | 1 Principles | `CORE` |

Rule format, kinds, layers and precedence follow [03 · Standards](../../docs/design/03-standards.md), plus one part
the owner approved on 2026-11-03: **Review by**, the date by which the rule's owner checks the rule is still right.
